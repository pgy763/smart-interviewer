# 截图说明

这些图是 `tools/shot.py` 用 headless Edge 自动跑出来并断言的，不是手摆的。

**重要：画面里的「人脸」是合成的测试视频，不是真人。**

`tools/make_fake_y4m.py` 用 Pillow 画了一个椭圆肤色块（占比 17%）当假摄像头输入，
通过 `--use-file-for-fake-video-capture` 喂给 Edge。原因很简单：headless 环境
没有摄像头，而 Edge 自带那个绿色 pacman 测试图**没有肤色区域**，视觉启发式会
正确地判「未检测到人脸」——截图看着像链路坏了，其实是算法在工作。

它证明的是「抽帧 → 本地视觉启发式 → 落库 → 报告出视觉统计」这条链路通了，
**不证明**「人脸识别准确」。报告里的「看镜头比例」也是基于同一个合成视频算的，
所以是 100%。

真要用的时候，换成真摄像头就行，代码路径完全一样。
